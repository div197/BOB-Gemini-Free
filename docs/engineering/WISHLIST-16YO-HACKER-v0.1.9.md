## 📐 Detailed Architectural Specifications

### 🧮 Wish 1: Interactive Tokenizer & BPE Visualizer (`/tools/tokenizer`)
* **The Student Need**: "Why does `strawberry` have three 'r's but LLMs sometimes fail to count them? How does tokenization work for Hindi/Sanskrit, Python indentation, and LaTeX math?"
* **The Solution**: A built-in interactive modal and floating tool that slices text in real-time with alternating color badges, showing token IDs, character-to-token compression ratio, and vocabulary mechanics.

### 🐍 Wish 2: Interactive Pyodide/WASM Python Sandbox
* **The Student Need**: "When the AI writes a Python script with Matplotlib or numerical algorithms, I want to see the charts and output immediately without installing Python virtual environments."
* **The Solution**: Client-side Pyodide WebAssembly sandbox with a sleek `RUN WASM ⚡` button on every Python code block.

### ⚔️ Wish 3: Multi-Model Arena & Side-by-Side Comparison
* **The Student Need**: "I want to see how `gemini-3.7-flash-thinking` compares to `claude-5-sonnet` and `gpt-5.6-sol` on the exact same complex math proof or coding problem."
* **The Solution**: Split-screen arena mode rendering simultaneous SSE streaming responses, step-by-step reasoning tokens, and performance metrics side-by-side.

### 🪄 Wish 4: Prompt Engineering & System Persona Lab
* **The Student Need**: "I want to learn how to prompt like a senior AI researcher and give my AI persistent personas (e.g. Socratic Math Tutor, Senior Go Engineer)."
* **The Solution**: Preset persona templates, temperature sliders, and 1-click prompt enhancement (`⌘+Shift+P`).

### 📦 Wish 5: Portable Offline Student Distribution
* **The Student Need**: "I want to carry this on a USB stick and run it on my school lab computer or my friend's PC without installing Go, Python, or administrative permissions."
* **The Solution**: Self-contained single binary with embedded HTML/JS web studio and 0 external dependencies.

### 🔌 Wish 6: Hackable Student Sidecar API
* **The Student Need**: "I want to teach the AI to query my local SQLite database or run a local Python script using tool/function calling."
* **The Solution**: Clean, modular function calling pipeline with custom user tool definitions in `config.json`.

### 🏆 Wish 7: Gamified AI Mastery & Savings Telemetry
* **The Student Need**: "I want to feel proud of my learning progress and see how much money I saved my family while becoming a master engineer."
* **The Solution**: Milestone badges (*100k Tokens Processed*, *First Reasoning Proof*, *First Python WASM Run*, *$10 Saved*).
